# College Management System

A College Management System built using Python and MySQL.

## Features

- Student Management
- Course Management
- Faculty Management
- Enrollment Management
- Payment Management
- Reports Generation

## Technologies Used

- Python
- MySQL
- mysql-connector-python

## Database Tables

- Students
- Courses
- Faculty
- Enrollments
- Payments
- Admins
